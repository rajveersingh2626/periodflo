A cross-platform mobile application engineered for cycle tracking, symptom forecasting, and dual-partner health synchronization.

---

## Features

- **Predictive Cycle Modeling**: Algorithmic forecasting for period windows, ovulation intervals, and phase transitions.
- **Partner Sync Engine**: Secure pairing mechanism enabling partners to stay synchronized on cycle phases, energy levels, and mood forecasts.
- **Privacy First & Local Encrypted State**: Complete client-side sovereignty over sensitive health telemetry.
- **Cross-Platform**: Universal deployment across iOS, Android, and Web using Expo 52 and Metro bundler.

---

## Tech Stack

- **Framework**: React Native 0.76+ via Expo SDK 52
- **Navigation**: Expo Router (file-based routing)
- **Language**: TypeScript (strict mode)
- **Styling**: NativeWind / Tailwind CSS
- **Testing**: Vitest unit test suite

---

## Getting Started

### Prerequisites
- Node.js 18+
- Expo Go app on iOS or Android (or Xcode / Android Studio for emulators)

### Installation
```bash
git clone https://github.com/rajveersingh2626/periodflo.git
cd periodflo
npm install
```

### Running Locally
```bash
# Start Expo development server
npm run start

# Run on Android emulator / device
npm run android

# Run on iOS simulator
npm run ios

# Run web build
npm run web

# Run tests
npm run test
```
